## 3. Present Tense

The simple present tense -- "I go," "we eat," "she reads" -- you have already seen in the last chapter.

You just add the person endings (**[2.2](Verbs.md)**) to the dictionary form (or verb stem (**[2.1](Verbs.md)**)).

Let's use a new verb, **dolé** 'to sell':

| Person              | Letter      | Example                                     |
| ------------------- | ----------- | ------------------------------------------- |
| I                   | (base form) | **dolé**<br/>I sell                         |
| you (singular)      | **-l**      | **dolel**<br/>you (singular) sell           |
| he<br/>she<br/>it   | **-r**      | **doler**<br/>he, she, it sells             |
| we (including you)  | **-t**      | **dolet**<br/>we sell, including you        |
| we (and not you)    | **-v**      | **dolev**<br/>we sell, not you              |
| you (plural), y'all | **-c**      | **dolec**<br/>you (plural) sell, y'all sell |
| they                | **-d**      | **doled**<br/>they sell                     |

### 3.1 More Verbs

​	**vefa** (*to play*)

​	**stufe** (*to dance*)

​	**estú** (*to eat*)

Now try making simple sentences with what you know:

| English     | Kotava |
| ----------- | ------ |
| They dance. |        |
| She eats.   |        |

Answers: 

​	**Stufed.** (*They dance.*) 

​	**Estur.** (*She eats.*)

As you'll see [later](Pronouns.md), **estur** by itself can mean *he eats, she eats*, or *it eats*.
